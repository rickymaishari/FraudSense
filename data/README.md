# Dataset attribution

Source reference: https://www.kaggle.com/datasets/ealaxi/paysim1

Edgar A. Lopez-Rojas, Ahmed Elmir and Stefan Axelsson, *PaySim: A financial
mobile money simulator for fraud detection*, EMSS, 2016.

The original project's saved publisher metadata identifies the dataset as
CC BY-SA 4.0: https://creativecommons.org/licenses/by-sa/4.0/
Data-derived row examples and prediction tables in this distribution retain
that attribution and license. Rows have been selected, features engineered,
and predictions added; no endorsement by the original authors is implied.
The full raw dataset is not redistributed.

The local full archive passed CRC verification. The actual CSV has 6,362,620
rows, 8,213 fraud labels, no missing values and no exact duplicate rows.
CSV SHA-256: `16910f90577b0d981bf8ff289714510bb89bc71bff7d3f220f024e287e4eea6b`.
The filename/content match PaySim, but the historical download chain cannot
be independently authenticated from this local archive alone.
